Como construir Listas

Tipos de Listas

Lista Não Ordenada

Uma lista não ordenada usa marcadores (bolinhas)

  • Use a tag   < ul >  

Exemplo de Código

< ul > Lista não Ordenada
  < li > Item1 < /li >
  < li > Item2 < /li >
  < li > Item3 < /li >
< /ul >


Resultado

  • Item1
  • Item2
  • Item3

Lista Ordenada

Uma lista ordenada usa números ou letras para mostrar uma sequência( use "type="a/A/1/i/I" para escolher o tipo de lista ordenada )

  • Use a tag   < ol >  

Exemplo de Código 1

< ol type="1" > Lista 1,2,3...
  < li > Item1 < /li >
  < li > Item2 < /li >
  < li > Item3 < /li >
< /ol >

Resultado

  1. Item1
  2. Item2
  3. Item3

  3. Item3
