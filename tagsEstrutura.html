Tags de Estrutura

O que são?

tags de estrutura HTML são os elementos básicos que organizam o esqueleto e o layout de uma página web.

Tags de Estrutura Básica

  •   < !DOCTYPE html >   Informa ao navegador a versão do HTML utilizada (HTML5).

  •   < html >   É a raiz que engloba todo o conteúdo da página.

  •   < head >   Guarda as informações invisíveis (metadados), como o título e a codificação.

  •   < body >   Guarda as informações invisíveis (metadados), como o título e a codificação.

Tags de Layout & Semântica

  •   < header >   Representa o cabeçalho, usado para menus de navegação ou introduções.

  •   < nav >   Define uma seção com links de navegação.

  •   < main >   Indica o conteúdo principal e central da página.

  •   < section >   Agrupa conteúdos que possuem um tema em comum.

  •   < article >   Define um conteúdo independente e completo, como uma postagem de blog.

  •   < aside >   Guarda conteúdos secundários ou barras laterais.

  •   < footer >   : Representa o rodapé, com links úteis, contatos e direitos autorais.

Tag de Divisão Genérica

  •   < div >   : Um bloco genérico invisível usado para agrupar elementos e ajudar na estilização.
