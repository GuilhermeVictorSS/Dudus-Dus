Como criar Tabelas

Para que servem?

As tabelas HTML servem exclusivamente para organizar e exibir dados tabulares — ou seja, informações que fazem sentido quando dispostas em linhas e colunas, como planilhas, horários, tabelas de preços e estatísticas

Tags para a criação de Tabelas

  •   < table >   Cria a tabela.

  •   < tr >   Define uma linha da tabela.

  •   < th >   Define uma célula de cabeçalho (geralmente em negrito).

  •   < td >   Define uma célula com dados comuns.



 Código

< table >
  < tr >
    < th > Nome < /th >
    < th > Idade < /th >
    < th > Estado < /th >
  < /tr >
  < tr >
    < td > Dudu < /td >
    < td > 25 < /td >
    < td > São Paulo < /td >
  < /tr >
  < tr >
    < td > Dus < /td >
    < td > 30 < /td >
    < td > Rio de Janeiro < /td >
  < /tr >
< /table >

Resultado

Nome Idade Estado
Dudu 25 São Paulo
Dus 30 Rio de Janeiro
