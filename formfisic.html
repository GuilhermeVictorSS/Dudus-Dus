Tags de Formatação Física

O que são?

   Os formatos físicos de HTML (geralmente chamados de tags de formatação física ou tags de estilo visual) são elementos que servem para alterar a aparência visual do texto diretamente, sem atribuir a ele nenhum significado semântico ou importância estrutural.


 Tags:

  •   < b >   Deixa o texto em negrito apenas por estética, sem indicar que a palavra é importante.

  •   < i >   Deixa o texto em itálico apenas por estilo visual.

  •   < u >   Sublinha o texto.

  •   < tt >   Exibe o texto em fonte monoespaçada (estilo máquina de escrever).

  •   < strike >   ou   < s >   Exibe o texto tachado (com um risco no meio).

  •   < big >   Aumenta o tamanho da fonte em relação ao texto ao redor.

  •   < small >   Diminui o tamanho da fonte.


Tags de Formatação Lógica

O que são?

   Os formatos lógicos de HTML (também chamados de tags de formatação lógica ou semântica) são elementos que definem o significado ou a importância do texto que envolvem, e não apenas a sua aparência visual.Ao contrário dos formatos físicos (que apenas dizem ao navegador para deixar o texto em negrito ou itálico), as tags lógicas informam aos motores de busca (como o Google) e aos leitores de tela para deficientes visuais por que aquele texto está destacado.


 Tags:

  •   < strong >   Indica que o texto tem forte importância ou urgência. Por padrão, o navegador o exibe em negrito.

  •   < em >   Indica ênfase (ênfase enfática). Por padrão, o navegador o exibe em itálico.

  •   < code >   Define um pedaço de código de computador. Usa uma fonte monoespaçada.

  •   < cite >   Define o título de uma obra (livro, música, filme, etc.).

  •   < abbr >   Define uma abreviação ou sigla (pode usar o atributo title para mostrar o significado ao passar o mouse).

  •   < ins >   Define um texto que foi inserido/adicionado ao documento (geralmente fica sublinhado).

  •   < del >   Define um texto que foi deletado/removido (geralmente fica riscado).
